# Discord に貼る用マニュアル

2 回に分けて貼る（Discord の 1 投稿 2000 文字制限のため）。

## 1通目（使い方）

```
📚 **在庫探偵の使い方**

本のコードを貼るだけで、書店の店頭在庫をまとめて調べます。

**■ 調べ方**
`9784088852676` ← ISBN（本の裏のバーコード、978 から始まる13桁）を貼るだけ
`9784088852676 全国` ← 後ろに「全国」を付けると全国の店
`9784088852676 京都` ← 県名を付けるとその県だけ
`B0XXXXXXXX` や Amazon の URL でもOK（Amazon が拒否したら ISBN で）
何も付けなければ **愛知＋京都** を調べます。返事まで 15 秒ほど、全国は 1 分ほど。

**■ 結果の見方**
`📘 TSUTAYA / 蔦屋書店 愛知 25/26` → 在庫のある店 25 ／ 確認した店 26。店名を押すとサイトが開く
`📘 大曽根店 ─ 多い` → 在庫あり　`─ 少ない` → 残りわずか　`─ 2個` → 数が分かる店
在庫なしの店は数に入るだけで、行には出ません。
頭の絵文字は系列の目印です（📘TSUTAYA 📙三洋堂 📕三省堂 📗丸善ジュンク堂 📒未来屋 📔紀伊國屋 🔵くまざわ 🟠えみたす …）。
先頭には Keepa の価格推移グラフが付きます。

**■ 区画**
📍 愛知 ／ 📍 京都 … 県ごとに分かれています
🔗 リンク・要確認 … 自動で読めない店のリンク（Amazon、Keepa、宮脇書店 など）
📱📞 自動検索できない店 … アプリ（ほんらぶ・Honya Club）や電話で確認する店
```

## 2通目（注意とコマンド）

```
**■ スラッシュコマンド**
`/zaiko code:9784088852676` … 検索（`area:全国` や `area:京都` で範囲指定）
`/local code:9784088852676` … 地元だけ
`/stores` … 対応している書店の一覧

**■ 注意**
・同じコードは 5 分間、前の結果を使い回します。
・書店サイトの都合で ⚪要確認 や ⚠️失敗 が出ることがあります。その場合はリンクから直接見てください。
・ブックオフ、ヴィレヴァン、大垣書店の自社サイトは自動で読めません（在庫データが公開されていないため）。
・日販系の店（えみたす など）の在庫が止まったときは bot が知らせます。復旧したら自動で出るようになります。
・雑誌の JAN（491 から始まる）は、対応していない店が「要確認」になります。
```

## 運用メモ（管理者向け）

- bot は自宅 PC の `ドキュメント\買取スキャナー` フォルダにある。起動はデスクトップの「買取スキャナー 起動」（画面なし、ログは `data\bot.log`）、
  停止は「買取スキャナー 停止」。フォルダ内の `start.bat` なら黒い画面つきで起動。サインイン時の自動起動は `autostart.bat`。
  初回やフォルダを動かしたいときは `setup.bat`（移動・環境作成・ボタン作成を一度にやる）。
- 更新は `update.bat` をダブルクリック → 黒い画面を閉じて `start.bat` をもう一度（`.env` は残る）。
- 設定は `.env`（トークン、Webhook、検索範囲の既定、待機時間など）。
- 店の追加・無効化は `/addstore` `/togglestore`（サーバー管理権限が必要）か `stores.json`。
